# Imágenes y Postales · Universo visual

Portal estático de herramientas visuales gratuitas para GitHub Pages.

- `index.html`: portada y buscador.
- `herramientas/index.html`: catálogo filtrable.
- `herramientas/<slug>/index.html`: página individual por herramienta.
- `assets/js/catalog.js`: catálogo central.
- `assets/js/app.js`: navegación y búsqueda.
- `assets/js/tool-engine.js`: motor compartido de procesamiento local.
- `assets/css/site.css`: diseño responsive.

Reglas: no publicar herramientas sin función real; procesar localmente cuando sea posible; mantener URLs estables; probar SEO, accesibilidad, rendimiento y móvil.

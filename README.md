# Imagenes y Postales

Reconstrucción editorial de https://imagenesypostales.com/ como biblioteca temática de conocimiento, conciencia y cosmos.

## Primera etapa
- Portada estática, semántica y responsive.
- 15 categorías temáticas aprobadas y subcategorías registradas en `data/categories.json`.
- Criterios editoriales y de fidelidad a las fuentes en `EDITORIAL.md`.
- Metadatos básicos, canonical, Open Graph y datos estructurados WebSite.
- CSS liviano, sin frameworks ni dependencias externas.

## Principios técnicos
- Mobile-first, HTML semántico y accesible.
- Contenido principal disponible en HTML, no dependiente de JavaScript para ser leído.
- No cargar scripts de redes sociales ni comentarios en la portada.
- No insertar anuncios hasta contar con la configuración real de AdSense y haber comprobado el cumplimiento de sus políticas.
- Crear páginas indexables solamente cuando tengan contenido original y suficiente.

## Próximas etapas
1. Crear páginas informativas y de políticas con contenido real y específico.
2. Diseñar el modelo de publicación con fuente, cita, explicación, contexto, referencias y enlaces relacionados.
3. Crear páginas de categoría cuando exista contenido editorial para sostenerlas.
4. Integrar compartir por WhatsApp y Facebook; en Instagram ofrecer compartir nativo del dispositivo o copiar enlace.
5. Evaluar comentarios externos con moderación, carga diferida y controles antispam.
6. Preparar sitemap.xml y robots.txt a partir de las URLs finales verificadas.
7. Revisar rendimiento, accesibilidad, SEO técnico y políticas de AdSense antes de publicar en producción.

## Publicación
La primera versión se está construyendo en la rama `reconstruccion-editorial`. No se modifica `main` hasta revisar y aprobar el resultado.

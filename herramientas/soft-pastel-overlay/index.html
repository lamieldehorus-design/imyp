Qué hace esta herramienta y para qué sirve

La superposición pastel añade una capa de color suave que desplaza la apariencia de la fotografía hacia una paleta delicada. Podés elegir el tono pastel y ajustar la intensidad para conservar parte de los colores originales o transformar la atmósfera con mayor fuerza.

Cómo usar superposición pastel paso a paso

  1. Cargá la fotografía que querés suavizar cromáticamente.
  2. Elegí el color pastel que acompañará la imagen.
  3. Ajustá la intensidad para regular cuánto se percibe la capa.
  4. Compará distintos tonos y observá cómo cambian las áreas claras y oscuras.
  5. Descargá la versión cuando la paleta resulte armónica.

Ejemplos prácticos

  • Crear una publicación de estética suave y delicada.
  • Unificar una serie de fotografías con una paleta pastel.
  • Preparar fondos para invitaciones y piezas editoriales.

Dónde y cuándo conviene usarla

Usala cuando querés una atmósfera cromática suave. Para una capa de color más intensa, probá superposición de color; para un degradado multicolor, elegí degradado de malla.

Consejos para obtener un buen resultado

Los tonos pastel funcionan mejor con intensidad moderada. Revisá que la capa no elimine demasiado contraste ni vuelva ilegibles los detalles.

Preguntas frecuentes

¿Puedo elegir el tono pastel?

Sí. El color de la capa es configurable.

¿Qué controla la intensidad?

La fuerza con la que se aplica el tono.

¿Es un degradado?

No. Es una superposición de un color pastel.

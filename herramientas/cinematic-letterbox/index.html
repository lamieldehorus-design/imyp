Qué hace esta herramienta y para qué sirve

El encuadre cinematográfico agrega bandas horizontales para presentar la fotografía con una proporción panorámica. Podés elegir la relación de aspecto y el color de las bandas para crear una presentación inspirada en la pantalla de cine.

Cómo usar encuadre cinematográfico paso a paso

  1. Cargá la fotografía que querés presentar en formato panorámico.
  2. Ajustá la proporción para definir la relación entre ancho y alto.
  3. Elegí el color de las bandas, normalmente negro para un estilo cinematográfico clásico.
  4. Revisá cuánto espacio de la imagen queda visible dentro del encuadre.
  5. Descargá la composición con las bandas aplicadas.

Ejemplos prácticos

  • Dar un acabado de cine a fotografías de viaje.
  • Crear una portada panorámica para un video o publicación.
  • Preparar una imagen con proporción de pantalla ancha.

Dónde y cuándo conviene usarla

Usala cuando buscás una presentación panorámica sin cambiar la escena principal. Si necesitás adaptar la imagen a un lienzo de dimensiones concretas, usá lienzo de dimensiones exactas.

Consejos para obtener un buen resultado

Elegí una proporción acorde al destino y revisá que las bandas no tapen información importante. El color negro es clásico, pero otros tonos pueden funcionar con un diseño creativo.

Preguntas frecuentes

¿Qué controla la proporción?

La relación panorámica entre ancho y alto del encuadre.

¿Puedo cambiar el color de las bandas?

Sí. El color es configurable.

¿Es lo mismo que recortar una foto?

Agrega bandas para simular un formato panorámico; no es una herramienta de recorte convencional.

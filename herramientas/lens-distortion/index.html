Qué hace esta herramienta y para qué sirve

La distorsión de lente curva la imagen para imitar ciertas perspectivas de objetivos gran angulares o de ojo de pez. El control de intensidad define cuánto se deforman las líneas y los bordes de la fotografía.

Cómo usar distorsión de lente paso a paso

  1. Cargá una fotografía con líneas o formas que permitan apreciar la distorsión.
  2. Ajustá la intensidad para definir cuánto se curva la imagen.
  3. Empezá con un valor bajo y observá cómo cambian los bordes.
  4. Aumentá gradualmente si buscás un efecto de ojo de pez más evidente.
  5. Descargá la versión cuando la deformación tenga el estilo deseado.

Ejemplos prácticos

  • Crear una estética de ojo de pez para una fotografía urbana.
  • Dar un aspecto experimental a retratos y objetos.
  • Simular una perspectiva gran angular en una composición.

Dónde y cuándo conviene usarla

Usala como recurso creativo o para explorar perspectivas. No reemplaza la corrección óptica de lente para un trabajo técnico; si necesitás líneas rectas y proporciones fieles, conservá el original.

Consejos para obtener un buen resultado

Las distorsiones fuertes deforman rostros y objetos cercanos a los bordes. Probá primero con intensidad baja y revisá la composición completa.

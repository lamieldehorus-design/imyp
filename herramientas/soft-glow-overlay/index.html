Qué hace esta herramienta y para qué sirve

El resplandor suave superpone una luz difusa que envuelve la imagen y suaviza su apariencia. La intensidad define cuánto se percibe el brillo y el radio determina qué tan extendido resulta el halo.

Cómo usar resplandor suave paso a paso

  1. Cargá la fotografía a la que querés agregar luz difusa.
  2. Ajustá la intensidad para controlar la presencia del resplandor.
  3. Configurá el radio para definir cuánto se extiende el halo.
  4. Probá valores graduales y observá cómo cambia la suavidad de la imagen.
  5. Descargá la versión cuando el brillo acompañe el estilo buscado.

Ejemplos prácticos

  • Dar una atmósfera luminosa a un retrato.
  • Suavizar luces en una fotografía de producto.
  • Crear un fondo etéreo para una portada o invitación.

Dónde y cuándo conviene usarla

Usala cuando quieras una luz general y difusa. Para resaltar solo los bordes, elegí contorno con resplandor; para un brillo concentrado en altas luces, probá bloom.

Consejos para obtener un buen resultado

Un radio grande puede reducir la definición general. Ajustá primero la intensidad y luego el radio para controlar el halo sin perder demasiado detalle.

Preguntas frecuentes

¿Qué controla la intensidad?

La fuerza visual de la capa luminosa.

¿Qué modifica el radio?

La extensión del resplandor alrededor de la imagen.

¿Es igual a bloom?

No. Este efecto agrega una capa difusa general; bloom enfatiza las zonas luminosas.

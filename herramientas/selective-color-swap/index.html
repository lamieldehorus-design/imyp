Qué hace esta herramienta y para qué sirve

La sustitución selectiva de color busca un tono de origen y lo reemplaza por un color nuevo. El control de tolerancia define qué tan amplio es el rango de colores similares que también se modifican.

Cómo usar sustitución selectiva de color paso a paso

  1. Cargá la fotografía donde querés reemplazar un color.
  2. Elegí el color original que querés sustituir.
  3. Seleccioná el nuevo color que ocupará su lugar.
  4. Ajustá la tolerancia para incluir más o menos tonos cercanos al original.
  5. Revisá las zonas afectadas y descargá la imagen cuando el cambio sea consistente.

Ejemplos prácticos

  • Cambiar el color de un objeto en una fotografía de producto.
  • Adaptar una prenda o elemento a una paleta de marca.
  • Crear variantes cromáticas de una misma imagen.

Dónde y cuándo conviene usarla

Usala cuando el color que querés reemplazar sea reconocible y esté relativamente separado de otros tonos. Si solo querés destacar un color, probá ajuste selectivo; para conservar un color y atenuar los demás, usá aislar color.

Consejos para obtener un buen resultado

La tolerancia es importante cuando el color aparece con sombras y reflejos. Ajustala con cuidado para evitar modificar elementos que no querías cambiar.

Preguntas frecuentes

¿Puedo elegir el color nuevo?

Sí. Seleccionás el color de origen y el color de reemplazo.

¿Qué controla la tolerancia?

La amplitud de tonos cercanos al color original que se sustituyen.

¿Cambia toda la imagen?

Afecta los píxeles que coinciden con el color objetivo dentro de la tolerancia.

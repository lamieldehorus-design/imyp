Qué hace esta herramienta y para qué sirve

Los rayos cromáticos superponen haces de luz con variaciones de color para crear una apariencia prismática. Podés elegir cuántos rayos aparecen y regular la intensidad para controlar cuánto dominan la fotografía.

Cómo usar rayos cromáticos paso a paso

  1. Cargá la fotografía donde querés proyectar los rayos.
  2. Definí la cantidad de haces que aparecerán.
  3. Ajustá la intensidad para controlar la presencia de las bandas cromáticas.
  4. Probá diferentes cantidades y observá cómo se distribuyen los colores.
  5. Descargá la imagen cuando el efecto tenga el impacto deseado.

Ejemplos prácticos

  • Crear una portada con haces de luz multicolor.
  • Añadir una atmósfera prismática a un retrato.
  • Diseñar fondos gráficos con rayos y bandas de color.

Dónde y cuándo conviene usarla

Es útil para composiciones luminosas y efectos de color. Para rayos de un solo tono, usá rayos de sol; para bandas arcoíris, probá prisma arcoíris.

Consejos para obtener un buen resultado

Una cantidad alta de rayos puede saturar la composición. Ajustá la intensidad para conservar el motivo principal.

Preguntas frecuentes

¿Qué controla la cantidad?

El número de rayos que se superponen a la imagen.

¿Qué hace la intensidad?

Regula la fuerza visual de los haces cromáticos.

¿Es un efecto de luz real?

Es una superposición gráfica inspirada en la dispersión de luz y color.

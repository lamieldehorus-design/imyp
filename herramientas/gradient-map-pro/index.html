Qué hace esta herramienta y para qué sirve

El mapa de degradado transforma la escala tonal asignando un color a las sombras y otro a las luces. A diferencia de una capa uniforme, el efecto responde a la luminosidad de cada zona y crea una transición entre ambos tonos.

Cómo usar mapa de degradado paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Elegí el color que representará las sombras.
  3. Seleccioná el color destinado a las luces.
  4. Probá combinaciones con contraste suficiente para conservar las formas.
  5. Descargá la imagen cuando la paleta represente el estilo buscado.

Ejemplos prácticos

  • Crear una portada con colores de marca.
  • Convertir un retrato en una composición gráfica de dos tonos.
  • Diseñar fondos con una paleta limitada y coherente.

Dónde y cuándo conviene usarla

Usalo cuando quieras colorear de forma distinta las zonas claras y oscuras. Para un color uniforme, elegí capa de color; para controlar explícitamente el punto medio, probá duotono avanzado.

Consejos para obtener un buen resultado

Los colores elegidos deben diferenciarse lo suficiente para que las formas sigan siendo visibles. Probá tonos claros y oscuros con una relación de contraste clara.

Preguntas frecuentes

¿Qué hace un mapa de degradado?

Asigna colores a las zonas según su luminosidad, en lugar de aplicar un tinte uniforme.

¿Puedo elegir los dos colores?

Sí. Hay selectores separados para sombras y luces.

¿Es igual a una superposición de color?

No. El mapa responde a los tonos de la imagen; la superposición cubre la foto con un color uniforme.

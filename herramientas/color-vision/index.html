Qué hace esta herramienta y para qué sirve

El simulador permite previsualizar una imagen bajo distintos modelos de percepción cromática: protanopia, deuteranopia, tritanopia y escala de grises. Es una ayuda visual para revisar contrastes y combinaciones de color, no una herramienta de diagnóstico médico.

Cómo usar simulador de visión cromática paso a paso

  1. Cargá la imagen o diseño que querés revisar.
  2. Abrí el selector de simulación y elegí una de las opciones disponibles.
  3. Observá cómo cambian los colores y qué elementos pierden diferenciación.
  4. Repetí la prueba con las otras simulaciones para comparar el comportamiento de la paleta.
  5. Usá lo aprendido para reforzar contrastes, etiquetas o señales y conservá la imagen original.

Ejemplos prácticos

  • Revisar si un gráfico depende exclusivamente del rojo y el verde.
  • Comprobar la legibilidad de una infografía o interfaz.
  • Evaluar una paleta antes de publicar un diseño.

Dónde y cuándo conviene usarla

Es útil durante la revisión de gráficos, materiales educativos, interfaces y piezas de comunicación. Para mejorar accesibilidad, combiná el color con etiquetas, patrones, formas y diferencias de luminosidad.

Consejos para obtener un buen resultado

No tomes la simulación como una representación idéntica de la experiencia de cada persona. Es una previsualización orientativa: verificá siempre la legibilidad con más de una señal visual.

Preguntas frecuentes

¿Qué simulaciones ofrece?

Protanopia, deuteranopia, tritanopia y escala de grises.

¿Sirve para diagnosticar una condición visual?

No. Es una herramienta de previsualización de diseño, no un instrumento médico.

¿Qué puedo hacer si dos colores se confunden?

Sumá contraste de luminosidad, etiquetas, iconos o patrones para que la información no dependa solo del color.

Qué hace esta herramienta y para qué sirve

El campo de partículas luminosas distribuye pequeños puntos de luz sobre la fotografía para crear profundidad y una atmósfera brillante. Podés definir la cantidad de partículas, elegir el color y regular la intensidad del efecto.

Cómo usar campo de partículas luminosas paso a paso

  1. Cargá la fotografía donde querés sumar partículas.
  2. Ajustá la cantidad para definir cuántos puntos luminosos aparecen.
  3. Elegí el color de la luz para acompañar la escena.
  4. Regulá la intensidad para controlar el brillo de las partículas.
  5. Revisá la distribución y descargá el resultado.

Ejemplos prácticos

  • Crear un fondo espacial o mágico.
  • Añadir partículas luminosas a una portada musical.
  • Dar profundidad a una fotografía nocturna.

Dónde y cuándo conviene usarla

Es útil para efectos atmosféricos y fondos creativos. Para partículas más pequeñas tipo polvo, usá polvo de purpurina; para destellos en forma de estrella, elegí destellos estelares.

Consejos para obtener un buen resultado

La cantidad y la intensidad deben equilibrarse. Si los puntos cubren demasiado la fotografía, reducí la cantidad o bajá el brillo.

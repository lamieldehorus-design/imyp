¿Qué es crear etiqueta sobre imagen y para qué sirve?

Una etiqueta o badge es un bloque breve de texto que destaca una palabra, estado o llamada visual. Puede funcionar como sello promocional o identificador gráfico.

Agregá una etiqueta de texto destacada sobre una esquina de tu imagen. Personalizá el mensaje y el color para resaltar información.

Cómo usar crear etiqueta sobre imagen paso a paso

  1. Cargá la imagen
  2. escribí el texto breve
  3. elegí el color
  4. comprobá legibilidad y ubicación
  5. descargá la composición.

Ejemplos prácticos de uso

Destacá NUEVO en una ficha, agregá OFERTA a una promoción o identificá una pieza como DESTACADO.

Dónde y cuándo conviene utilizar esta herramienta

Útil en banners, miniaturas, promociones, catálogos y publicaciones sociales donde una palabra breve ordena la lectura.

Consejos para conseguir un buen resultado

Mantené el mensaje corto y elegí contraste suficiente. No tapes el elemento principal ni ubiques el texto demasiado cerca del borde.

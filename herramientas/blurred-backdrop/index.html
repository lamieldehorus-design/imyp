Qué hace esta herramienta y para qué sirve

El fondo desenfocado permite adaptar una fotografía a un lienzo de nuevas dimensiones sin dejar grandes espacios vacíos. Usa una copia ampliada y desenfocada como fondo, mientras la imagen principal se coloca encima con el ajuste elegido: mostrar completa o rellenar.

Cómo usar fondo desenfocado paso a paso

  1. Cargá la fotografía que querés adaptar a otro formato.
  2. Definí el ancho y el alto del nuevo lienzo en píxeles.
  3. Ajustá el desenfoque del fondo para controlar cuánto se suaviza la copia ampliada.
  4. Elegí Mostrar completa para conservar toda la foto o Rellenar para ocupar el espacio principal.
  5. Revisá los bordes y descargá la composición adaptada.

Ejemplos prácticos

  • Adaptar una foto horizontal a una publicación vertical.
  • Crear un fondo cuadrado para redes sin recortar el motivo principal.
  • Preparar una imagen para una presentación con un lienzo de proporciones distintas.

Dónde y cuándo conviene usarla

Es útil cuando necesitás cambiar la proporción y querés conservar la foto completa dentro de un lienzo más amplio. Si preferís recortar para llenar el formato sin fondo, usá redimensionar o recortar.

Consejos para obtener un buen resultado

Elegí dimensiones compatibles con el destino. Un desenfoque moderado suele mantener el fondo reconocible sin competir con la imagen principal.

Preguntas frecuentes

¿Qué aparece detrás de la foto?

Una copia ampliada y desenfocada de la misma imagen.

¿Puedo definir el tamaño del lienzo?

Sí. Podés ingresar ancho y alto en píxeles.

¿Qué diferencia hay entre Mostrar completa y Rellenar?

Mostrar completa conserva la imagen entera; Rellenar ocupa el espacio y puede recortar.

Privacidad y descarga

El procesamiento se realiza en tu navegador. No necesitás crear una cuenta para empezar. Conservá una copia del original y revisá el archivo exportado antes de publicarlo o compartirlo.

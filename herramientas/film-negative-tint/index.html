Qué hace esta herramienta y para qué sirve

El negativo teñido invierte la apariencia tonal de la fotografía y aplica una dominante cromática elegida. Podés seleccionar el tinte y regular la intensidad para crear un negativo clásico o una versión con una atmósfera de color distinta.

Cómo usar negativo teñido paso a paso

  1. Cargá la fotografía que querés convertir en negativo.
  2. Elegí el tinte que se aplicará sobre la inversión.
  3. Ajustá la intensidad para definir cuánto domina el color.
  4. Compará distintos tonos y observá cómo cambian luces y sombras.
  5. Descargá la versión que mejor funcione para tu composición.

Ejemplos prácticos

  • Crear un negativo digital con dominante azul o cálida.
  • Diseñar una portada experimental.
  • Explorar una paleta invertida para una pieza gráfica.

Dónde y cuándo conviene usarla

Usala para un negativo con un color elegido. Si necesitás controlar también el giro de tono y la saturación, probá negativo de color avanzado; para una inversión directa, elegí invertir colores.

Consejos para obtener un buen resultado

La inversión modifica mucho la lectura de la imagen. Ajustá la intensidad y el tinte de forma gradual y conservá el archivo original.

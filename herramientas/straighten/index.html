¿Qué es enderezar imagen y para qué sirve?

Enderezar una imagen corrige pequeñas inclinaciones mediante una rotación precisa. Podés indicar un ángulo en grados para nivelar un horizonte, una línea arquitectónica o un documento fotografiado.

Es útil cuando la cámara quedó ligeramente torcida o cuando una fotografía necesita alinearse antes de recortarla, publicarla o incorporarla a un diseño. La rotación puede generar esquinas vacías porque el lienzo se amplía para contener la imagen girada.

Cómo usar enderezar imagen paso a paso

  1. Cargá la fotografía que tiene una inclinación.
  2. Mové el control de ángulo hacia un valor positivo o negativo.
  3. Observá el horizonte, los bordes de edificios o las líneas que deberían quedar niveladas.
  4. Aplicá la corrección y revisá las esquinas que quedan fuera del área original.
  5. Si necesitás un borde rectangular, combiná el resultado con una herramienta de recorte.

Ejemplos prácticos de uso

Un horizonte inclinado puede corregirse con un pequeño giro. Una fotografía de un edificio puede alinearse mejor para que las líneas principales se vean más rectas. Un documento fotografiado puede quedar más cómodo de leer si la inclinación es leve.

Dónde y cuándo conviene utilizarla

Se utiliza en fotografía de paisajes, arquitectura, documentos, catálogos, presentaciones y preparación de imágenes para impresión o publicación.

Consejos para conseguir un buen resultado

Probá ángulos pequeños, por ejemplo entre -3° y 3°, antes de hacer correcciones mayores. Después de enderezar, puede ser necesario recortar las esquinas transparentes para obtener un rectángulo limpio.

Preguntas frecuentes

¿Qué ángulo debo usar?

Depende de la inclinación. Empezá con cambios pequeños y observá las líneas de referencia.

¿La imagen pierde partes al girar?

El lienzo se amplía para contener la rotación, por lo que pueden aparecer esquinas transparentes.

¿Puedo corregir una perspectiva deformada?

No. Esta herramienta rota la imagen; no corrige la perspectiva ni endereza líneas convergentes.

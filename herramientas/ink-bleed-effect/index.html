Qué hace esta herramienta y para qué sirve

La tinta expandida recrea la apariencia de pigmento que se extiende sobre una superficie absorbente. El control de expansión define cuánto se dispersa el efecto y el selector permite elegir el color de tinta.

Cómo usar tinta expandida paso a paso

  1. Cargá la fotografía o diseño que querés transformar.
  2. Elegí el color de tinta que se expandirá sobre la imagen.
  3. Ajustá la expansión para definir cuánto se extiende el pigmento.
  4. Probá valores graduales y observá cómo cambian los bordes y las formas.
  5. Descargá el resultado cuando la textura tenga el carácter deseado.

Ejemplos prácticos

  • Crear una estética de impresión artesanal.
  • Dar una apariencia de tinta sobre papel a una ilustración.
  • Diseñar fondos orgánicos para carteles y portadas.

Dónde y cuándo conviene usarla

Usala para tratamientos artísticos con bordes suaves y orgánicos. Para una textura de papel, probá papel gofrado o textura de papel; para un efecto de tinta de cómic, usá tinta de cómic.

Consejos para obtener un buen resultado

La expansión alta puede mezclar áreas cercanas. Elegí una imagen con formas claras y ajustá la fuerza del efecto para conservar la lectura.

Preguntas frecuentes

¿Qué controla la expansión?

La distancia o fuerza con la que la tinta parece extenderse.

¿Puedo elegir el color?

Sí. El color de tinta es configurable.

¿Es un filtro de impresión real?

No. Es una simulación visual de tinta expandida.

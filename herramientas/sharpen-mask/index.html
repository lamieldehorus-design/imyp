¿Qué es máscara de enfoque y para qué sirve?

Aumenta el contraste local alrededor de los bordes para que los detalles parezcan más definidos. No reconstruye información que la cámara no capturó.

Realzá los detalles mediante un enfoque de alta frecuencia con intensidad regulable. Mejorá la percepción de nitidez sin alterar la composición.

Cómo usar máscara de enfoque paso a paso

  1. Cargá una imagen ligeramente suave
  2. abrí la máscara
  3. ajustá intensidad gradualmente
  4. revisá bordes por si aparecen halos
  5. descargá cuando la nitidez sea natural.

Ejemplos prácticos de uso

Dónde y cuándo conviene utilizar esta herramienta

Útil al preparar imágenes para web y presentaciones. En fotos de producto revisá bordes y texturas para evitar apariencia artificial.

Consejos para conseguir un buen resultado

Aplicá el enfoque después de definir el tamaño final. Si aparecen halos claros u oscuros, reducí la intensidad.

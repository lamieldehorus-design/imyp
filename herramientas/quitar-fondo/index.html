Cómo quitar el fondo de una imagen

  1. Seleccioná la foto que querés editar.
  2. Presioná Quitar el fondo y esperá a que termine el procesamiento.
  3. Descargá el resultado como PNG para conservar la transparencia.

Los bordes pueden variar según la foto, la iluminación y la complejidad del fondo. Para mejores resultados, usá una imagen nítida con el sujeto bien diferenciado del fondo.

Crear imágenes con fondo transparente

Quitar el fondo de una foto resulta útil para preparar imágenes de productos, retratos, perfiles, presentaciones y composiciones gráficas. El resultado se descarga como PNG para conservar las zonas transparentes y poder colocarlo sobre otro color o diseño. Las fotos con el sujeto bien iluminado y separado del fondo suelen ofrecer mejores resultados que las imágenes borrosas o con contornos muy complejos.

La primera ejecución puede demorar más porque el navegador necesita cargar los recursos de procesamiento. El tiempo depende del equipo, la conexión y el tamaño de la imagen. Revisá los bordes del cabello, los objetos finos y las áreas transparentes antes de usar el archivo final. Si necesitás terminar de preparar la imagen, podés recortar el encuadre, ajustar el tamaño o comprimir una copia para la web.

Preguntas frecuentes sobre quitar fondos

¿En qué formato se descarga la imagen?

Se descarga como PNG, un formato que permite conservar la transparencia del fondo eliminado.

¿Por qué el primer procesamiento tarda más?

La herramienta puede necesitar descargar los recursos del modelo de IA la primera vez. El tiempo varía según el dispositivo y la conexión.

¿Todas las fotos quedan perfectas?

No siempre. Los resultados dependen del contraste, la iluminación y la complejidad de los bordes; revisá la vista previa antes de descargar.

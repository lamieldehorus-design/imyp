Qué hace esta herramienta y para qué sirve

El borde de papel rasgado crea una terminación irregular alrededor de la fotografía, como una hoja arrancada a mano. Podés configurar el margen, la irregularidad del contorno y el color del papel para construir una presentación artesanal.

Cómo usar borde de papel rasgado paso a paso

  1. Cargá la fotografía que querés enmarcar.
  2. Ajustá el margen en píxeles para definir el ancho del papel.
  3. Regulá la irregularidad para hacer el borde más suave o más quebrado.
  4. Elegí el color del papel según la paleta de la fotografía.
  5. Revisá todo el perímetro y descargá la composición.

Ejemplos prácticos

  • Crear una lámina de estilo scrapbook.
  • Enmarcar una foto de viaje con apariencia artesanal.
  • Diseñar una invitación o portada con estética de collage.

Dónde y cuándo conviene usarla

Es útil para composiciones creativas y recuerdos. Para un borde limpio, usá marco fotográfico; para una textura fibrosa sobre toda la foto, probá textura de papel.

Consejos para obtener un buen resultado

Una irregularidad moderada suele verse más natural. Ajustá el margen para que el papel no reduzca demasiado el área visible de la fotografía.

Preguntas frecuentes

¿Puedo elegir cuánto se rasga el borde?

Sí. El control de irregularidad define la forma del contorno.

¿Qué controla el margen?

El ancho del papel alrededor de la fotografía.

¿Puedo cambiar el color?

Sí. El color del papel es configurable.

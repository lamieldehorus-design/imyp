Qué hace esta herramienta y para qué sirve

La lámina holográfica agrega reflejos iridiscentes que cambian de color según la dirección visual, evocando una superficie metalizada u holográfica. Podés regular la intensidad y el ángulo para orientar el patrón de reflejos.

Cómo usar lámina holográfica paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Ajustá la intensidad para definir cuánto se percibe el efecto iridiscente.
  3. Configurá el ángulo en grados para orientar la distribución de los reflejos.
  4. Probá distintos valores y observá cómo interactúan los colores con la imagen.
  5. Descargá la versión cuando el brillo holográfico tenga el impacto deseado.

Ejemplos prácticos

  • Crear una portada con estética holográfica.
  • Dar un acabado iridiscente a una tarjeta o etiqueta.
  • Diseñar fondos digitales con reflejos multicolor.

Dónde y cuándo conviene usarla

Es útil para composiciones llamativas y recursos gráficos. Para una refracción de cristal, probá prisma de cristal cromático; para bandas arcoíris, elegí prisma arcoíris.

Consejos para obtener un buen resultado

El efecto funciona mejor cuando tiene zonas oscuras y claras donde los reflejos puedan distinguirse. Evitá una intensidad tan alta que cubra los detalles.

Preguntas frecuentes

¿Qué significa holográfico?

Hace referencia a reflejos iridiscentes que cambian de color según la dirección.

¿Qué controla el ángulo?

La orientación del patrón de reflejos.

¿Es una lámina física?

No. Es una superposición digital inspirada en superficies holográficas.

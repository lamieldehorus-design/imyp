Qué hace esta herramienta y para qué sirve

El creador de miniaturas adapta una imagen a dimensiones exactas de ancho y alto. Podés elegir entre rellenar el espacio, recortando lo que no entre, o contener la imagen completa y completar el espacio sobrante con un fondo configurable.

Cómo usar creador de miniaturas paso a paso

  1. Cargá la fotografía o diseño que querés convertir en miniatura.
  2. Ingresá el ancho y el alto deseados en píxeles.
  3. Elegí Rellenar si querés ocupar todo el lienzo, aceptando un posible recorte.
  4. Elegí Contener si necesitás conservar la imagen completa y configurá el fondo para el espacio libre.
  5. Revisá el encuadre y descargá la miniatura con las dimensiones definidas.

Ejemplos prácticos

  • Crear imágenes de vista previa para artículos o videos.
  • Preparar miniaturas uniformes para un catálogo.
  • Adaptar fotografías a tarjetas, listados o galerías.

Dónde y cuándo conviene usarla

Usala cuando el destino requiere medidas precisas. Antes de elegir Rellenar o Contener, decidí si es más importante llenar el marco o conservar todo el contenido.

Consejos para obtener un buen resultado

Comprobá las dimensiones solicitadas por la plataforma de destino. Si elegís Rellenar, ubicá el sujeto cerca del área segura; con Contener, elegí un fondo que combine con la imagen.

Preguntas frecuentes

¿Puedo definir el tamaño exacto?

Sí. Configurás ancho y alto en píxeles.

¿Qué diferencia hay entre Rellenar y Contener?

Rellenar ocupa el lienzo y puede recortar; Contener mantiene la imagen completa y puede dejar espacio libre.

¿Puedo elegir el color del espacio sobrante?

Sí. El editor ofrece un selector de fondo.

Privacidad y descarga

El procesamiento se realiza en tu navegador. No necesitás crear una cuenta para empezar. Conservá una copia del original y revisá el archivo exportado antes de publicarlo o compartirlo.

Qué hace esta herramienta y para qué sirve

La viñeta cromática suave aplica una transición radial en los bordes de la fotografía para dirigir la atención hacia el centro. Podés elegir el color, ajustar la intensidad y definir el radio para decidir cuánto espacio queda menos afectado.

Cómo usar viñeta cromática suave paso a paso

  1. Cargá la fotografía que querés tratar.
  2. Elegí el color de la viñeta para definir la atmósfera de los bordes.
  3. Ajustá la intensidad para regular la fuerza del efecto.
  4. Configurá el radio en porcentaje para ampliar o reducir el área central.
  5. Revisá las esquinas y descargá la versión que mejor acompañe la imagen.

Ejemplos prácticos

  • Enfatizar un retrato centrado con bordes teñidos.
  • Crear una atmósfera cromática en paisajes.
  • Dar profundidad a una fotografía de producto.

Dónde y cuándo conviene usarla

Es útil cuando querés combinar una viñeta con un color específico. Para una viñeta oscura clásica, usá viñeta fotográfica; para una transición radial más luminosa, probá degradado radial.

Consejos para obtener un buen resultado

El radio y la intensidad determinan el equilibrio entre centro y bordes. Evitá oscurecer detalles importantes o usar un color que compita con el sujeto.

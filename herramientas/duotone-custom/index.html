Qué hace esta herramienta y para qué sirve

El duotono reemplaza la lectura cromática habitual por una combinación de dos colores: uno destinado a las sombras y otro a las luces. Al elegir ambos tonos, podés construir una estética reconocible para carteles, portadas, publicaciones y piezas de marca.

Cómo usar duotono personalizado paso a paso

  1. Cargá la fotografía que querés convertir en una composición de dos tonos.
  2. Abrí el selector de color de sombras y elegí el tono que representará las zonas oscuras.
  3. Elegí por separado el color de luces para las zonas claras.
  4. Probá combinaciones con contraste suficiente y observá cómo se conservan las formas.
  5. Ajustá los dos colores hasta lograr una paleta coherente y descargá la imagen.

Ejemplos prácticos

  • Crear una portada con dos colores de marca.
  • Dar una estética gráfica a retratos para redes sociales.
  • Preparar fondos e ilustraciones con una paleta limitada.

Dónde y cuándo conviene usarla

Es ideal cuando querés una imagen con personalidad cromática fuerte y menos colores que la fotografía original. Para reducir la cantidad de niveles tonales sin imponer dos colores, podés usar posterización.

Consejos para obtener un buen resultado

Combiná tonos que se distingan entre sí. Un color oscuro para sombras y uno luminoso para luces suele facilitar la lectura, pero también podés experimentar con paletas complementarias o monocromáticas.

Preguntas frecuentes

¿Puedo elegir los dos colores?

Sí. El editor ofrece selectores independientes para sombras y luces.

¿El efecto conserva la fotografía original?

La imagen se reinterpreta visualmente mediante dos colores, por lo que cambia su apariencia cromática.

¿Es lo mismo que posterizar?

No. El duotono asigna dos colores a sombras y luces; la posterización reduce niveles de tono.

Privacidad y descarga

El procesamiento se realiza en tu navegador. No necesitás crear una cuenta para empezar. Conservá una copia del original y revisá el archivo exportado antes de publicarlo o compartirlo.

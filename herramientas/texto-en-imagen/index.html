HERRAMIENTA GRATUITA PARA IMÁGENES

Añadir texto a una imagen online

Convertí una fotografía en una imagen con mensaje, saludo o título. Escribí tu texto, elegí tamaño y color, y prepará una copia para compartir en redes, chats o páginas web.

Abrir herramienta gratuita →

Privacidad: el editor procesa tus imágenes en el navegador. No necesitás crear una cuenta ni subir el archivo a un servidor para realizar estas operaciones.

Qué podés hacer

Personalizá el mensaje

Agregá una frase, un título o unas palabras para acompañar tu fotografía.

Elegí tamaño y color

Ajustá el tamaño del texto y elegí un color para mejorar su visibilidad.

Descargá para compartir

Creá una imagen nueva en PNG y conservá la fotografía original.

Cómo añadir texto a una imagen

  1. Cargá una fotografía o imagen.
  2. Elegí la herramienta de texto, escribí el mensaje y ajustá tamaño y color.
  3. Procesá la imagen, revisá la vista previa y descargá el resultado.

Preguntas frecuentes

¿Puedo crear una imagen con una frase?

Sí. Cargá una imagen, escribí tu frase y ajustá el texto antes de descargar el resultado.

¿Puedo usarlo para crear memes?

Podés añadir texto a una imagen. Para un meme con texto superior e inferior y una plantilla específica, visitá el creador de imágenes.

¿La foto original se modifica?

No. El editor genera una copia procesada en tu navegador. El archivo original permanece en tu dispositivo.

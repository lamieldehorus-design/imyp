Crear imágenes con frases, títulos y mensajes

Añadir texto a una imagen es una forma sencilla de preparar saludos, anuncios, citas, invitaciones o publicaciones para redes sociales. Elegí una fotografía que deje espacio para las palabras, escribí un mensaje breve y ajustá el tamaño y el color para que se lea con claridad. Un contraste suficiente entre las letras y el fondo ayuda a que el texto siga siendo legible en pantallas pequeñas.

Antes de descargar, revisá que el mensaje no tape la parte importante de la foto y que no quede demasiado cerca de los bordes. La herramienta genera una nueva imagen y no reemplaza el archivo original. Si querés añadir una identificación discreta en lugar de un mensaje, podés usar la herramienta de marca de agua. También podés crear una imagen con una frase o explorar las postales para personalizar y compartir.

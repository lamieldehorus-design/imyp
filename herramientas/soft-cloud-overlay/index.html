Qué hace esta herramienta y para qué sirve

Las nubes suaves superponen manchas difusas de luz que aportan una atmósfera envolvente. Podés elegir el color de las nubes, regular la intensidad y ajustar la escala para decidir cuánto espacio ocupan.

Cómo usar nubes suaves paso a paso

  1. Cargá la fotografía donde querés sumar la atmósfera luminosa.
  2. Elegí el color de las nubes para acompañar la paleta de la imagen.
  3. Ajustá la intensidad para definir cuánto se percibe el efecto.
  4. Configurá la escala para hacer las manchas más pequeñas o más amplias.
  5. Revisá la composición y descargá el resultado cuando el efecto sea sutil y equilibrado.

Ejemplos prácticos

  • Crear una atmósfera etérea para retratos.
  • Dar suavidad a un fondo para una invitación.
  • Añadir una luz difusa a una portada de estilo onírico.

Dónde y cuándo conviene usarla

Es útil para efectos atmosféricos y fondos suaves. Para un halo centrado, usá halo de enfoque suave; para una capa translúcida con color, probá cristal degradado.

Consejos para obtener un buen resultado

Elegí tonos que acompañen la iluminación de la foto. Una intensidad moderada conserva los detalles y evita que las nubes parezcan manchas opacas.

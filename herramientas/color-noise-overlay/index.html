Qué hace esta herramienta y para qué sirve

El ruido de color agrega pequeñas variaciones cromáticas sobre la fotografía. La cantidad define cuánta textura aparece y la opacidad regula su presencia, permitiendo crear desde un grano discreto hasta una interferencia de color más visible.

Cómo usar ruido de color paso a paso

  1. Cargá la fotografía que querés texturizar.
  2. Ajustá la cantidad de ruido para definir cuánta variación cromática aparece.
  3. Regulá la opacidad para controlar cuánto se percibe la capa.
  4. Revisá zonas lisas y detalles finos para comprobar que el ruido no domine.
  5. Descargá la imagen cuando la textura acompañe el estilo buscado.

Ejemplos prácticos

  • Dar una apariencia analógica a una fotografía digital.
  • Crear una textura de señal o ruido para un fondo.
  • Añadir grano cromático a una portada o pieza gráfica.

Dónde y cuándo conviene usarla

Es útil para texturas generales de color. Si buscás grano de película, probá grano de película en color; para una interferencia VHS más completa, elegí efecto VHS.

Consejos para obtener un buen resultado

El ruido se nota especialmente en cielos y superficies lisas. Ajustá cantidad y opacidad por separado para no perder detalle.

Preguntas frecuentes

¿Qué controla la cantidad?

La densidad o fuerza del ruido cromático generado.

¿Qué hace la opacidad?

Regula cuánto se ve la capa de ruido.

¿Es igual al grano de película?

No. Este efecto agrega ruido cromático; el grano de película busca una textura fotográfica analógica.

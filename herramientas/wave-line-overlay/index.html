Qué hace esta herramienta y para qué sirve

La trama de ondas agrega líneas curvas repetidas sobre la fotografía para crear un patrón fluido. Podés controlar la separación entre líneas, elegir su color y ajustar la intensidad para decidir cuánto domina la textura.

Cómo usar trama de ondas paso a paso

  1. Cargá la fotografía que querés decorar con ondas.
  2. Ajustá la separación en píxeles para definir la densidad de la trama.
  3. Elegí el color de las líneas para que contraste con la imagen.
  4. Regulá la intensidad para controlar cuánto se percibe el patrón.
  5. Revisá el resultado y descargá la composición.

Ejemplos prácticos

  • Crear fondos gráficos con ondas fluidas.
  • Añadir una textura decorativa a una portada.
  • Diseñar una pieza editorial con líneas curvas.

Dónde y cuándo conviene usarla

Es útil para composiciones gráficas y fondos con ritmo visual. Para ondas que deforman la fotografía, usá distorsión ondulada; para curvas topográficas, probá líneas topográficas.

Consejos para obtener un buen resultado

Una separación amplia deja respirar la fotografía. Bajá la intensidad si las líneas ocultan detalles o texto.

Preguntas frecuentes

¿Qué controla la separación?

La distancia entre las líneas onduladas.

¿Puedo cambiar el color?

Sí. El color de línea es configurable.

¿Es una deformación de la foto?

No. Superpone una trama de líneas; no ondula el contenido de la imagen.

Qué hace esta herramienta y para qué sirve

Las guías de encuadre superponen referencias visuales sobre la imagen para ayudarte a componer y planificar un recorte. Podés elegir la regla de tercios, centro y diagonales o una zona segura, además de ajustar el color y la opacidad de las líneas.

Cómo usar guías de encuadre paso a paso

  1. Cargá la fotografía que querés analizar o preparar para recorte.
  2. Elegí el tipo de guía: regla de tercios, centro y diagonales o zona segura.
  3. Seleccioná un color que contraste con la fotografía.
  4. Ajustá la opacidad para que las líneas se vean sin ocultar los detalles.
  5. Usá las referencias para decidir el encuadre y descargá o continuá editando según tu flujo de trabajo.

Ejemplos prácticos

  • Ubicar un rostro cerca de una intersección de la regla de tercios.
  • Comprobar que un título quede dentro de una zona segura.
  • Revisar el centro y las diagonales antes de recortar una imagen.

Dónde y cuándo conviene usarla

Es una herramienta de apoyo para fotografía, diseño y preparación de piezas para redes. Si necesitás cambiar las dimensiones o recortar de verdad, continuá con la herramienta de recorte correspondiente.

Consejos para obtener un buen resultado

Las guías son referencias de composición, no límites obligatorios. Activá la que mejor se adapte al objetivo y bajá la opacidad si dificulta evaluar la foto.

Preguntas frecuentes

¿Qué tipos de guía ofrece?

Regla de tercios, centro y diagonales, y zona segura.

¿Puedo cambiar el color de las líneas?

Sí. El color de las guías es configurable.

¿La guía recorta automáticamente la imagen?

No. Superpone referencias para ayudarte a planificar el encuadre.

Privacidad y descarga

El procesamiento se realiza en tu navegador. No necesitás crear una cuenta para empezar. Conservá una copia del original y revisá el archivo exportado antes de publicarlo o compartirlo.

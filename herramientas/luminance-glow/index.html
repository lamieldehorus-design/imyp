Qué hace esta herramienta y para qué sirve

El resplandor de luminancia detecta las zonas brillantes de la fotografía y les agrega un halo suave. El umbral define qué áreas se consideran luminosas, mientras la intensidad y el color determinan la presencia del resplandor.

Cómo usar resplandor de luminancia paso a paso

  1. Cargá una fotografía con luces o reflejos visibles.
  2. Ajustá el umbral para definir qué zonas recibirán el resplandor.
  3. Elegí el color del brillo para acompañar la iluminación.
  4. Regulá la intensidad para controlar la fuerza del halo.
  5. Revisá las altas luces y descargá la imagen cuando el brillo sea equilibrado.

Ejemplos prácticos

  • Acentuar luces de ciudad en una fotografía nocturna.
  • Dar un acabado cinematográfico a reflejos y superficies brillantes.
  • Crear una atmósfera luminosa para una portada.

Dónde y cuándo conviene usarla

Es útil cuando querés realzar solo las áreas luminosas. Para un halo más general, probá resplandor suave; para un resplandor cromático alrededor de altas luces, elegí halation de color.

Consejos para obtener un buen resultado

El umbral ayuda a evitar que el efecto se aplique a demasiadas zonas. Ajustalo antes de subir mucho la intensidad.

Preguntas frecuentes

¿Qué controla el umbral de luz?

Define qué niveles de luminosidad reciben el resplandor.

¿Puedo elegir el color del brillo?

Sí. El color es configurable.

¿Qué hace la intensidad?

Regula la fuerza del halo aplicado a las zonas luminosas.

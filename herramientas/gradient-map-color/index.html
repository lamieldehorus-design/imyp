Qué hace esta herramienta y para qué sirve

El mapa de degradado reasigna las zonas oscuras y claras de la fotografía a dos colores elegidos. La intensidad controla cuánto se transforma la imagen y permite conservar parte de la paleta original o aplicar un tratamiento más marcado.

Cómo usar mapa de degradado paso a paso

  1. Cargá la fotografía que querés colorear.
  2. Elegí el color que representará las sombras.
  3. Seleccioná el color destinado a las luces.
  4. Ajustá la intensidad para regular cuánto se aplica el mapa.
  5. Compará el resultado con la imagen original y descargá la variante elegida.

Ejemplos prácticos

  • Crear una paleta de marca para una portada.
  • Dar una estética de dos tonos a un retrato.
  • Preparar fondos gráficos con una combinación cromática limitada.

Dónde y cuándo conviene usarla

Es útil para reinterpretar la imagen según su luminosidad. Si querés un color para sombras y otro para luces con controles adicionales, probá duotono avanzado; para un tinte uniforme, usá superposición de color.

Consejos para obtener un buen resultado

Los dos colores deben mantener suficiente diferencia para que las formas se distingan. Ajustá la intensidad antes de descartar una combinación de tonos.

Preguntas frecuentes

¿Qué controla la intensidad?

La fuerza con la que se aplica el tratamiento cromático.

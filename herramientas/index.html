Preguntas frecuentes sobre las herramientas de imágenes

¿Las herramientas para imágenes son gratuitas?

Sí, las utilidades disponibles en esta página se pueden usar sin crear una cuenta. Algunas funciones avanzadas podrían incorporarse en futuras versiones.

¿Mis imágenes se suben a un servidor?

Las herramientas compatibles procesan las imágenes localmente en tu navegador. Tus archivos originales permanecen en tu dispositivo.

¿Qué formatos puedo usar?

Podés cargar formatos de imagen compatibles con tu navegador y exportar a los formatos que la herramienta ofrece. La disponibilidad exacta puede variar según el navegador y el dispositivo.

Herramientas online para editar imágenes, fotos y gráficos

Este directorio reúne utilidades gratuitas para resolver tareas habituales con imágenes desde el navegador: reducir el peso de una foto, cambiar sus dimensiones, convertir formatos, recortar bordes, corregir la orientación, añadir texto o aplicar una marca de agua. También incluye opciones para quitar el fondo de una imagen y crear los archivos favicon de una página web. Cada herramienta cuenta con instrucciones propias para que puedas elegir la operación adecuada y descargar una copia del resultado.

Para preparar imágenes para una web, suele ser útil ajustar primero el encuadre y las dimensiones y después revisar el formato y el peso. Si estás diseñando contenido para compartir, podés combinar las herramientas con el creador de imágenes y las postales listas para personalizar. Las funciones se ejecutan en el navegador cuando la herramienta lo permite; el rendimiento y los formatos disponibles pueden variar según el equipo y el navegador.

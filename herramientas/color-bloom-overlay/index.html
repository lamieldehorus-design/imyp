Qué hace esta herramienta y para qué sirve

El bloom de color crea una expansión luminosa teñida que suaviza las áreas brillantes y aporta una atmósfera de luz. Podés elegir el color, regular la intensidad y definir el radio para controlar cuánto se extiende el brillo.

Cómo usar bloom de color paso a paso

  1. Cargá la fotografía donde querés añadir el bloom.
  2. Elegí el color que tendrá la expansión luminosa.
  3. Ajustá la intensidad para definir cuánto destaca el brillo.
  4. Configurá el radio en porcentaje para controlar la extensión del efecto.
  5. Revisá las zonas luminosas y descargá la imagen cuando el bloom esté equilibrado.

Ejemplos prácticos

  • Dar un acabado brillante a una portada.
  • Acentuar luces y reflejos de una fotografía de producto.
  • Crear una atmósfera cromática suave para un retrato.

Dónde y cuándo conviene usarla

Usala cuando quieras una expansión luminosa con color. Para un halo neutro sobre las altas luces, probá resplandor bloom; para un resplandor exterior, elegí resplandor suave.

Consejos para obtener un buen resultado

El color y el radio cambian mucho el resultado. Empezá con una intensidad moderada para no cubrir los detalles de la fotografía.

Preguntas frecuentes

¿Puedo elegir el color del bloom?

Sí. El color de la expansión luminosa es configurable.

¿Qué controla el radio?

La extensión del brillo, expresada en porcentaje.

¿Qué hace la intensidad?

Regula la fuerza con la que se percibe el bloom.

Qué hace esta herramienta y para qué sirve

El degradado de malla combina varios focos de color para formar una transición orgánica sobre la fotografía. Podés elegir tres colores y regular la opacidad para controlar cuánto se integra el degradado con la imagen original.

Cómo usar degradado de malla paso a paso

  1. Cargá la fotografía que querés utilizar como base.
  2. Elegí el primer color de la malla.
  3. Seleccioná el segundo y el tercer color para ampliar la paleta.
  4. Ajustá la opacidad para definir cuánto se superpone el degradado.
  5. Revisá la transición de colores y descargá la composición.

Ejemplos prácticos

  • Crear fondos abstractos con varios colores.
  • Aplicar una atmósfera cromática a una fotografía de producto.
  • Diseñar una portada con degradados orgánicos.

Dónde y cuándo conviene usarla

Usala cuando una transición lineal o radial resulte demasiado simple. Para dos colores en una sola dirección, probá baño de color degradado; para un halo centrado, elegí degradado radial.

Consejos para obtener un buen resultado

Elegí colores que armonicen entre sí. Una opacidad baja deja ver más la fotografía y una alta convierte la malla en el elemento principal.

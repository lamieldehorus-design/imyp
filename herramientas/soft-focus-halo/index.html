Qué hace esta herramienta y para qué sirve

El halo de enfoque suave crea una zona luminosa y difusa alrededor del centro de la fotografía. El radio define el tamaño del halo, la intensidad regula su presencia y el color permite adaptar el efecto a la atmósfera de la imagen.

Cómo usar halo de enfoque suave paso a paso

  1. Cargá la fotografía donde querés crear el halo.
  2. Ajustá el radio en porcentaje para definir el tamaño del área luminosa.
  3. Elegí el color del halo para acompañar la paleta de la imagen.
  4. Regulá la intensidad para hacer el efecto sutil o más evidente.
  5. Revisá que el halo no tape el sujeto y descargá el resultado.

Ejemplos prácticos

  • Destacar un objeto central con una luz suave.
  • Crear una atmósfera cálida para un retrato.
  • Dar profundidad a un fondo para una portada.

Dónde y cuándo conviene usarla

Usalo cuando querés un halo central difuso. Para iluminar los bordes, elegí resplandor de bordes; para un halo que rodea toda la fotografía, probá resplandor suave.

Consejos para obtener un buen resultado

El radio define cuánto espacio ocupa el efecto. Un halo más amplio puede suavizar demasiado el centro, así que ajustá la intensidad con cuidado.

Preguntas frecuentes

¿Qué controla el radio?

El tamaño del halo alrededor del centro.

¿Puedo cambiar el color?

Sí. El color del halo es configurable.

¿Qué diferencia hay con resplandor suave?

Este efecto concentra el halo alrededor del centro; el otro aplica un brillo más general.

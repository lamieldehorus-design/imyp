Qué hace esta herramienta y para qué sirve

El reflejo brillante agrega una banda de luz diagonal que simula una superficie pulida o una capa reflectante. Podés controlar la intensidad del brillo y el ángulo para orientar la reflexión.

Cómo usar reflejo brillante paso a paso

  1. Cargá la fotografía donde querés sumar el reflejo.
  2. Ajustá la intensidad para definir cuánto se percibe la banda luminosa.
  3. Configurá el ángulo en grados para orientar el reflejo diagonal.
  4. Probá distintas inclinaciones y observá cómo interactúa la luz con el motivo.
  5. Descargá la composición cuando el reflejo aporte profundidad sin distraer.

Ejemplos prácticos

  • Dar una apariencia pulida a una imagen de producto.
  • Crear una tarjeta visual con un brillo diagonal.
  • Añadir un acabado brillante a una portada.

Dónde y cuándo conviene usarla

Es útil para diseños de producto, tarjetas y composiciones que necesitan una superficie luminosa. Para una placa translúcida con degradado, probá cristal degradado; para un destello puntual, usá destello de lente.

Consejos para obtener un buen resultado

El reflejo debe acompañar la dirección visual de la imagen. Usá intensidad moderada para que no parezca una franja opaca.

Preguntas frecuentes

¿Puedo orientar el reflejo?

Sí. El ángulo se configura en grados.

¿Qué controla la intensidad?

La fuerza del brillo diagonal.

¿Es un reflejo realista de un objeto?

Qué hace esta herramienta y para qué sirve

El degradado de dos tonos transforma la escala tonal de una fotografía asignando un color a las sombras y otro a las luces. El punto medio define dónde se produce la transición entre ambos, lo que permite construir paletas gráficas con más matices que un duotono rígido.

Cómo usar degradado de dos tonos paso a paso

  1. Cargá una fotografía con luces y sombras reconocibles.
  2. Elegí el color que representará las zonas oscuras.
  3. Seleccioná el color destinado a las zonas claras.
  4. Ajustá el punto medio para desplazar el equilibrio entre ambos colores.
  5. Probá la paleta sobre distintas áreas de la foto y descargá el resultado.

Ejemplos prácticos

  • Crear portadas con una identidad cromática de dos tonos.
  • Convertir retratos en piezas gráficas de alto contraste.
  • Diseñar fondos y recursos visuales con colores de marca.

Dónde y cuándo conviene usarla

Es una buena opción para una estética de póster, portadas o publicaciones. Si preferís un efecto de dos colores sin ajustar la transición, probá el duotono personalizado.

Consejos para obtener un buen resultado

Elegí colores que mantengan contraste suficiente. El punto medio modifica el balance entre sombras y luces, así que pequeños cambios pueden alterar mucho el carácter final.

Preguntas frecuentes

¿Qué diferencia hay con el duotono personalizado?

Esta herramienta agrega un control de punto medio para ajustar la transición tonal.

¿Puedo elegir ambos colores?

Sí. Hay selectores separados para sombras y luces.

¿Qué hace el punto medio?

Define el valor tonal donde cambia el peso relativo de los dos colores.

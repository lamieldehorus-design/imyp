Qué hace esta herramienta y para qué sirve

El duotono luminoso asigna un color a las sombras y otro a las luces, y agrega un resplandor para realzar las áreas brillantes. Combina un tratamiento cromático de dos tonos con una sensación de luz más intensa.

Cómo usar duotono luminoso paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Elegí el color que representará las sombras.
  3. Seleccioná el color de las luces para definir la paleta duotono.
  4. Ajustá el porcentaje de resplandor para destacar las zonas luminosas.
  5. Compará el resultado y descargá la versión que mantenga contraste y detalle.

Ejemplos prácticos

  • Crear una portada con paleta de dos colores y luces intensas.
  • Dar un acabado futurista a un retrato.
  • Diseñar fondos gráficos con sombras profundas y altas luces brillantes.

Dónde y cuándo conviene usarla

Conviene para composiciones de alto impacto donde el color y la luz forman parte del estilo. Para un duotono sin brillo adicional, usá duotono personalizado o avanzado.

Consejos para obtener un buen resultado

Elegí colores con contraste y no exageres el resplandor. La luz debe reforzar las altas luces, no ocultar las formas de la fotografía.

Preguntas frecuentes

¿Qué colores puedo elegir?

Un color para sombras y otro para luces.

¿Qué hace el control de resplandor?

Agrega brillo a las zonas luminosas de la imagen.

¿Es igual a un duotono común?

Combina el mapa de dos tonos con un efecto de resplandor adicional.

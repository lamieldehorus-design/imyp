Qué hace esta herramienta y para qué sirve

El virado diagonal divide la fotografía mediante una transición inclinada y aplica un tono distinto a cada lado. Podés elegir los dos colores y regular la intensidad para construir una composición cromática partida.

Cómo usar virado diagonal paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Elegí el primer color que se aplicará a una mitad de la imagen.
  3. Seleccioná el segundo tono para la otra parte.
  4. Ajustá la intensidad para controlar cuánto dominan los colores.
  5. Revisá la transición diagonal y descargá la versión final.

Ejemplos prácticos

  • Crear una portada con dos atmósferas cromáticas.
  • Dividir visualmente una fotografía para una pieza editorial.
  • Diseñar fondos gráficos con contraste de color diagonal.

Dónde y cuándo conviene usarla

Usala cuando quieras dividir la imagen en dos áreas de color mediante una transición diagonal. Para colorear sombras y luces, elegí virado dividido; para un degradado continuo, probá baño de color.

Consejos para obtener un buen resultado

Elegí tonos que contrasten y revisá dónde pasa la diagonal respecto del sujeto. Evitá que la división corte un rostro o un elemento importante.

Preguntas frecuentes

¿Qué zonas reciben los dos colores?

Cada mitad de la imagen, separada por una transición diagonal.

¿Puedo elegir ambos tonos?

Sí. Hay selectores separados para los dos colores.

¿Qué controla la intensidad?

La fuerza con la que se aplica el virado.

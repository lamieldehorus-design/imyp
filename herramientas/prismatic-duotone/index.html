Qué hace esta herramienta y para qué sirve

El duotono prismático combina un virado de dos colores para sombras y luces con reflejos inspirados en la refracción de un prisma. Podés elegir ambos tonos y ajustar la intensidad para controlar cuánto domina la transformación.

Cómo usar duotono prismático paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Elegí el color que representará las sombras.
  3. Seleccioná el color destinado a las luces.
  4. Ajustá la intensidad para regular la fuerza del duotono y sus reflejos.
  5. Compará el resultado con el original y descargá la versión final.

Ejemplos prácticos

  • Crear una portada con dos tonos y reflejos iridiscentes.
  • Dar un acabado futurista a un retrato.
  • Diseñar fondos gráficos con una paleta de color intensa.

Dónde y cuándo conviene usarla

Es útil para composiciones cromáticas de alto impacto. Para un duotono sin reflejos, usá duotono avanzado; para un efecto prismático sin mapa tonal, probá lámina holográfica.

Consejos para obtener un buen resultado

Elegí colores con contraste y ajustá la intensidad con moderación. Conservá suficiente detalle para que el motivo principal siga siendo reconocible.

Preguntas frecuentes

¿Qué colores puedo elegir?

Un tono para sombras y otro para luces.

¿Qué agrega el efecto prismático?

Reflejos cromáticos inspirados en la refracción de un prisma.

¿Qué controla la intensidad?

La fuerza global del tratamiento de dos tonos y reflejos.

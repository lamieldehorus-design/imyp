Qué hace esta herramienta y para qué sirve

La hoja de contactos reúne varias miniaturas en una sola composición, como las planchas usadas para revisar fotografías antes de elegir una toma. Podés definir la cantidad de columnas, el espacio entre imágenes y el color de fondo.

Cómo usar hoja de contactos paso a paso

  1. Seleccioná las fotografías que querés reunir en la hoja.
  2. Definí la cantidad de columnas según el número de imágenes y el formato final.
  3. Ajustá la separación en píxeles para ordenar las miniaturas.
  4. Elegí un color de fondo que ayude a distinguir las fotografías.
  5. Revisá el conjunto y descargá la hoja de contactos.

Ejemplos prácticos

  • Comparar una selección de tomas de una sesión fotográfica.
  • Preparar una vista general de imágenes para un cliente.
  • Organizar fotografías de un evento en una sola lámina.

Dónde y cuándo conviene usarla

Es práctica para selección, revisión y presentación de varias imágenes. Si querés una composición más decorativa con fotos en una cuadrícula, usá cuadrícula de fotografías.

Consejos para obtener un buen resultado

Elegí una cantidad de columnas que permita reconocer cada miniatura. Una separación moderada evita que las imágenes se mezclen visualmente.

Preguntas frecuentes

¿Puedo incluir varias fotos?

Sí. La hoja de contactos está pensada para reunir múltiples imágenes.

¿Qué puedo personalizar?

Cantidad de columnas, separación y color de fondo.

¿Es igual a una cuadrícula de fotos?

Tiene un enfoque de hoja de revisión con miniaturas y numeración, mientras la cuadrícula es una composición más general.

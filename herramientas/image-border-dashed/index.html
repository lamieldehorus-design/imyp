Qué hace esta herramienta y para qué sirve

El borde discontinuo crea un marco formado por trazos separados en lugar de una línea continua. Podés ajustar el grosor, el largo de cada trazo y el color para lograr una terminación decorativa o técnica.

Cómo usar borde discontinuo paso a paso

  1. Cargá la fotografía que querés enmarcar.
  2. Ajustá el grosor de la línea discontinua en píxeles.
  3. Definí el largo de cada trazo para hacer el patrón más fino o más marcado.
  4. Elegí el color del borde según el fondo y la paleta de la imagen.
  5. Revisá las cuatro esquinas y descargá la composición.

Ejemplos prácticos

  • Crear un marco de estilo artesanal o cuaderno.
  • Destacar una imagen en una presentación o ficha visual.
  • Diseñar una tarjeta con borde gráfico discontinuo.

Dónde y cuándo conviene usarla

Usala cuando un borde continuo resulte demasiado rígido y quieras una terminación segmentada. Para una línea sólida, elegí borde de color; para un marco de puntos, probá trama de lunares.

Consejos para obtener un buen resultado

El grosor y el largo de trazo deben mantener proporción. Un trazo muy largo puede parecer un borde continuo; uno muy corto puede generar una textura demasiado densa.

Preguntas frecuentes

¿Puedo cambiar la longitud de los trazos?

Sí. El control de largo de trazo se expresa en píxeles.

¿Puedo elegir el color?

Sí. El borde tiene un selector de color.

¿Qué diferencia hay con un borde continuo?

El marco se compone de segmentos separados, no de una línea uniforme.

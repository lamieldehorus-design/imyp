Qué hace esta herramienta y para qué sirve

La temperatura de color avanzada separa dos ajustes que suelen confundirse: la calidez, que desplaza la imagen hacia tonos cálidos o fríos, y el tinte, que permite compensar matices hacia otras direcciones cromáticas. Ambos controles trabajan en un rango de -100 a 100.

Cómo usar temperatura de color avanzada paso a paso

  1. Cargá la fotografía que querés corregir o estilizar.
  2. Ajustá la calidez para llevar la imagen hacia tonos más cálidos o más fríos.
  3. Modificá el tinte por separado para equilibrar matices que no se corrigen solo con temperatura.
  4. Hacé cambios pequeños y observá blancos, sombras y tonos de piel.
  5. Compará con el original y descargá la versión con el color más equilibrado.

Ejemplos prácticos

  • Corregir una foto con iluminación demasiado cálida.
  • Compensar una dominante de color verdosa o magenta mediante el tinte.
  • Unificar la apariencia de una serie de fotografías tomadas con luces distintas.

Dónde y cuándo conviene usarla

Conviene cuando necesitás un ajuste más específico que un simple control de temperatura. Si solo buscás un cambio cálido o frío rápido, la herramienta de temperatura básica puede ser suficiente.

Consejos para obtener un buen resultado

Ajustá primero la calidez y después el tinte. Cambiar ambos controles a la vez dificulta identificar cuál produjo la mejora.

Preguntas frecuentes

¿Qué diferencia hay entre calidez y tinte?

La calidez mueve la imagen hacia tonos cálidos o fríos; el tinte compensa matices cromáticos adicionales.

¿Qué rango tienen los controles?

Ambos trabajan de -100 a 100.

¿Es una corrección automática?

No. Son controles manuales para ajustar la apariencia de color.

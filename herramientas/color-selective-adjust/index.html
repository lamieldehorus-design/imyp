Qué hace esta herramienta y para qué sirve

El ajuste selectivo de color permite elegir un tono protagonista y reforzarlo dentro de la fotografía. El control de intensidad regula cuánto se destaca ese color, lo que ayuda a dirigir la atención sin cambiar toda la paleta por igual.

Cómo usar ajuste selectivo de color paso a paso

  1. Cargá la fotografía que querés editar.
  2. Elegí el color protagonista mediante el selector.
  3. Ajustá la intensidad para definir cuánto se refuerza ese tono.
  4. Revisá los objetos y zonas donde aparece el color elegido.
  5. Descargá el resultado cuando el color destacado tenga el protagonismo buscado.

Ejemplos prácticos

  • Resaltar el color de un producto en una fotografía.
  • Dar énfasis a un detalle cromático de un paisaje.
  • Crear una imagen promocional con un color de marca dominante.

Dónde y cuándo conviene usarla

Conviene cuando querés reforzar un color particular. Si buscás conservar un color y atenuar todos los demás, usá aislar color; si querés reemplazar un tono por otro, probá reemplazar color.

Consejos para obtener un buen resultado

Elegí un color que esté presente en el elemento que querés destacar. Ajustá la intensidad gradualmente para no crear un resultado artificial.

Preguntas frecuentes

¿Qué color se puede destacar?

El que elijas con el selector de color.

¿Qué controla la intensidad?

Cuánto se refuerza el color objetivo.

¿Es igual a aislar color?

No. El ajuste selectivo intensifica el color; aislar color atenúa el resto de la imagen.

Qué hace esta herramienta y para qué sirve

El virado de sombras y luces asigna colores diferentes a las zonas oscuras y claras de la fotografía. La intensidad regula cuánto se percibe el tratamiento, lo que permite crear desde una corrección sutil hasta una estética cinematográfica marcada.

Cómo usar virado de sombras y luces paso a paso

  1. Cargá la fotografía que querés tratar.
  2. Elegí el tono que se aplicará a las sombras.
  3. Seleccioná el color para las altas luces.
  4. Ajustá la intensidad para controlar cuánto se perciben ambos tonos.
  5. Compará la imagen completa y descargá la versión con el balance cromático deseado.

Ejemplos prácticos

  • Crear una atmósfera fría en sombras y cálida en luces.
  • Dar un acabado cinematográfico a un retrato o paisaje.
  • Unificar una serie de fotografías con una paleta de dos tonos.

Dónde y cuándo conviene usarla

Es útil cuando querés separar cromáticamente luces y sombras sin convertir toda la imagen en un único color. Para una asignación de dos tonos con punto medio explícito, probá duotono avanzado.

Consejos para obtener un buen resultado

Los tonos complementarios pueden generar contraste atractivo, pero conviene que no compitan con el sujeto. Ajustá la intensidad antes de cambiar los colores una y otra vez.

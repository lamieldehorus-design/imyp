Qué hace esta herramienta y para qué sirve

El marco con profundidad rodea la fotografía con un borde de varias capas que simula relieve y separación respecto del fondo. Podés ajustar el margen, elegir el color del marco y definir la profundidad para dar una sensación de volumen.

Cómo usar marco con profundidad paso a paso

  1. Cargá la fotografía que querés presentar con marco.
  2. Ajustá el margen en píxeles para definir el espacio exterior.
  3. Elegí el color del marco para acompañar la imagen.
  4. Configurá la profundidad para controlar cuánto sobresalen visualmente las capas.
  5. Revisá el volumen y descargá la composición.

Ejemplos prácticos

  • Presentar una fotografía como una tarjeta en relieve.
  • Crear una lámina para una galería o catálogo.
  • Dar profundidad visual a una portada o publicación.

Dónde y cuándo conviene usarla

Es útil cuando necesitás un marco con volumen. Para una sombra exterior más directa, usá sombra exterior; para un marco plano de color, elegí borde de color.

Consejos para obtener un buen resultado

Un margen suficiente ayuda a apreciar las capas. Elegí un color que contraste con la fotografía y mantené la profundidad proporcionada al tamaño final.

Preguntas frecuentes

¿Qué controles ofrece?

Margen, color del marco y profundidad.

¿Qué modifica la profundidad?

La separación visual entre las capas del marco.

¿Es igual a una sombra exterior?

No. Combina un marco de varias capas con sensación de relieve.

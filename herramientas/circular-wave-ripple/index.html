Qué hace esta herramienta y para qué sirve

Las ondas circulares generan anillos concéntricos que se expanden desde un punto de la imagen. Podés elegir cuántas ondas aparecen, seleccionar su color y regular la intensidad para crear una sensación de movimiento o vibración.

Cómo usar ondas circulares paso a paso

  1. Cargá la fotografía donde querés aplicar las ondas.
  2. Definí la cantidad de ondas para establecer cuántos anillos aparecerán.
  3. Elegí el color de las líneas para integrarlas con la imagen.
  4. Ajustá la intensidad para controlar cuánto se percibe el patrón.
  5. Revisá la distribución y descargá el resultado.

Ejemplos prácticos

  • Crear un fondo con ondas de propagación.
  • Dar una estética acuática o tecnológica a una portada.
  • Destacar un punto de interés con anillos concéntricos.

Dónde y cuándo conviene usarla

Es útil para patrones radiales y composiciones dinámicas. Para anillos luminosos, usá anillos luminosos; para ondas horizontales, probá distorsión ondulada.

Consejos para obtener un buen resultado

Una cantidad alta crea anillos más densos. Bajá la intensidad si las líneas cubren demasiado la fotografía.

Preguntas frecuentes

¿Qué controla la cantidad de ondas?

El número de anillos concéntricos que aparecen.

¿Puedo elegir el color?

Sí. El color de las ondas es configurable.

¿Es una animación?

No. El efecto se aplica como una composición estática.

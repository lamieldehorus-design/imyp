Qué hace esta herramienta y para qué sirve

El relieve de papel avanzado combina una textura de fibras con un efecto de relieve para simular una superficie prensada. La fuerza determina cuánto se perciben las elevaciones y la escala define el tamaño del patrón de textura.

Cómo usar relieve de papel avanzado paso a paso

  1. Cargá la fotografía o diseño que querés tratar.
  2. Ajustá la fuerza del relieve para definir cuánto sobresale la textura.
  3. Configurá la escala para controlar el tamaño de las fibras y el patrón.
  4. Probá distintos valores y observá cómo se integra la superficie con la imagen.
  5. Descargá el resultado cuando el relieve sea visible pero no excesivo.

Ejemplos prácticos

  • Crear una lámina con apariencia de papel artesanal prensado.
  • Dar textura a una invitación o portada.
  • Preparar un fondo con sensación material y relieve.

Dónde y cuándo conviene usarla

Es útil para una textura de papel más elaborada que un simple grano. Para un relieve más sencillo, probá papel gofrado; para una superficie granulada sin relieve, usá textura de papel.

Consejos para obtener un buen resultado

Una escala pequeña crea un patrón más fino. Ajustá la fuerza con moderación para no competir con textos o detalles de la fotografía.

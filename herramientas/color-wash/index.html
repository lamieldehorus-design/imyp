Qué hace esta herramienta y para qué sirve

El baño de color aplica un velo que transiciona entre dos tonos sobre la fotografía. Podés elegir los colores inicial y final, regular la intensidad y decidir si el degradado se desplaza en dirección vertical u horizontal.

Cómo usar baño de color degradado paso a paso

  1. Cargá la fotografía que querés teñir con un degradado.
  2. Elegí el color inicial y el color final de la transición.
  3. Ajustá la intensidad para controlar cuánto se superpone el velo.
  4. Seleccioná la dirección vertical u horizontal.
  5. Compará la transición sobre distintas zonas y descargá el resultado.

Ejemplos prácticos

  • Crear una atmósfera cromática para una campaña.
  • Unificar fotografías con dos colores de identidad visual.
  • Preparar fondos con degradado para títulos y publicaciones.

Dónde y cuándo conviene usarla

Usala cuando quieras aplicar una transición cromática sobre toda la imagen. Para un solo color uniforme, elegí capa de color; para un halo centrado, probá degradado radial.

Consejos para obtener un buen resultado

Elegí tonos que se complementen y regulá la intensidad con moderación. La dirección vertical funciona bien para cambios de cielo a suelo; la horizontal puede acompañar escenas panorámicas.

Preguntas frecuentes

¿Puedo elegir dos colores?

Sí. El efecto utiliza un color inicial y otro final.

¿Qué direcciones hay?

Vertical y horizontal.

¿Cómo hago el velo más discreto?

Reducí la intensidad del efecto.

Cómo usar el favicon

  1. Diseñá el icono o cargá tu propia imagen.
  2. Descargá el archivo ICO y los PNG que necesites.
  3. Subilos a la raíz de tu web o cambiá las rutas del código HTML.
  4. Guardá los cambios y actualizá la página. Si el icono anterior sigue apareciendo, probá borrar la caché del navegador.

Consejo: para que se lea bien en pestañas pequeñas, usá una forma sencilla, alto contraste y pocas letras.

Qué es un favicon y qué archivos necesita tu sitio

Un favicon es el pequeño icono que identifica una web en la pestaña del navegador, los favoritos y algunos accesos directos. Un diseño simple, reconocible y con buen contraste suele funcionar mejor que una imagen llena de detalles, especialmente en tamaños de 16 o 32 píxeles. Podés usar iniciales, una forma geométrica, un emoji o una imagen propia y comprobar cómo se ve antes de descargarlo.

El paquete incluye un archivo ICO, versiones PNG y un manifiesto web para que elijas los recursos apropiados para tu proyecto. Después de descargarlos, subí los archivos a tu sitio y revisá las rutas del código HTML generado antes de publicarlo. Si el icono anterior sigue apareciendo, el navegador puede estar mostrando una versión guardada en caché. Para preparar otros recursos gráficos, explorá todas las herramientas de imagen o convertí una imagen al formato que necesitás.

Preguntas frecuentes sobre favicons

¿Puedo usar un PNG como favicon?

Sí. Los navegadores modernos admiten PNG en el icono del sitio; el ICO sigue siendo útil para compatibilidad con distintos entornos.

¿Tengo que instalar el favicon en el sitio?

Sí. Descargá los archivos, subilos a tu web y agregá el código de instalación dentro de la sección head de tus páginas.

¿Por qué no veo el favicon nuevo?

Puede quedar guardada la versión anterior. Probá actualizar la página, abrir una ventana privada o limpiar la caché del navegador.

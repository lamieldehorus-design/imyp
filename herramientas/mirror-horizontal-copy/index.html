Qué hace esta herramienta y para qué sirve

El duplicado espejo horizontal genera una composición con dos mitades reflejadas de izquierda a derecha. La separación central permite decidir si ambas partes se tocan o si queda un espacio visible entre ellas.

Cómo usar duplicado espejo horizontal paso a paso

  1. Cargá la fotografía que querés duplicar.
  2. Definí la separación central en píxeles, comenzando con cero para una unión directa.
  3. Observá cómo se refleja la imagen de izquierda a derecha.
  4. Aumentá la separación si querés distinguir más claramente las dos mitades.
  5. Descargá la composición cuando la unión central se vea equilibrada.

Ejemplos prácticos

  • Crear composiciones simétricas para fondos y portadas.
  • Construir patrones gráficos a partir de una fotografía.
  • Dar un efecto espejo a paisajes, arquitectura o texturas.

Dónde y cuándo conviene usarla

Elegila cuando querés un reflejo lateral completo. Si preferís elegir qué mitad original se conserva, usá reflejar mitad de imagen; para un reflejo arriba y abajo, probá el duplicado vertical.

Consejos para obtener un buen resultado

Las fotografías con un motivo central o formas repetitivas suelen funcionar bien. Una separación de cero crea continuidad; agregá espacio si querés enfatizar el eje.

Preguntas frecuentes

¿En qué dirección se refleja?

De izquierda a derecha, formando una composición horizontal.

¿Puedo dejar un espacio en el centro?

Sí. Ajustá la separación central en píxeles.

¿Es lo mismo que reflejar mitad de imagen?

No. Esta herramienta crea un duplicado espejo; la otra permite elegir la mitad original.

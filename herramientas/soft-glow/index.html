Qué hace esta herramienta y para qué sirve

El resplandor suave genera un halo alrededor de la fotografía para separarla del fondo y darle una sensación luminosa. Podés elegir cuánto se difumina, regular la intensidad, seleccionar el color del resplandor y dejar margen exterior para que el halo tenga espacio.

Cómo usar resplandor suave paso a paso

  1. Cargá la fotografía a la que querés agregar un resplandor.
  2. Ajustá el desenfoque en píxeles para definir la suavidad del halo.
  3. Regulá la intensidad para decidir cuánto se percibe la luz.
  4. Elegí el color del resplandor y ajustá el margen exterior para evitar que quede cortado.
  5. Revisá el efecto alrededor de toda la imagen y descargá la versión final.

Ejemplos prácticos

  • Dar un halo cálido a una fotografía de producto.
  • Crear una pieza luminosa para redes sociales o una portada.
  • Separar una imagen de un fondo oscuro con un borde difuso.

Dónde y cuándo conviene usarla

Es útil para composiciones con una intención luminosa o atmosférica. Si necesitás una sombra en lugar de luz, usá sombra exterior; para iluminar una zona de la foto, probá degradado radial.

Consejos para obtener un buen resultado

El resplandor debe complementar la imagen, no reemplazarla. Elegí un color que armonice con la escena y aumentá el margen exterior si el halo toca los límites del lienzo.

Preguntas frecuentes

¿Puedo elegir el color del halo?

Sí. El editor incluye un selector para el color del resplandor.

¿Qué diferencia hay entre desenfoque e intensidad?

El desenfoque controla la suavidad; la intensidad regula la presencia del halo.

¿Para qué sirve el margen exterior?

Deja espacio alrededor de la foto para que el resplandor no quede recortado.

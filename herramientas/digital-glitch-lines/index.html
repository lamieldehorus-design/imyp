Qué hace esta herramienta y para qué sirve

Las líneas glitch digitales combinan una trama de líneas con pequeños desplazamientos para simular una señal alterada. Podés controlar la separación entre líneas, cuánto se desplazan y la intensidad general del efecto.

Cómo usar líneas glitch digitales paso a paso

  1. Cargá la fotografía que querés distorsionar.
  2. Ajustá la separación en píxeles para definir la densidad de las líneas.
  3. Configurá el desplazamiento para decidir cuánto se desalinean las franjas.
  4. Regulá la intensidad para controlar la fuerza del glitch.
  5. Revisá que la imagen conserve una lectura reconocible y descargá el resultado.

Ejemplos prácticos

  • Crear una portada de estética digital retro.
  • Dar una apariencia de interferencia a un retrato.
  • Diseñar fondos experimentales para música y eventos.

Dónde y cuándo conviene usarla

Es útil para efectos de señal y composiciones glitch. Para franjas horizontales más grandes, probá desplazamiento glitch; para una separación de canales RGB, usá glitch de canales.

Consejos para obtener un buen resultado

La separación y el desplazamiento afectan la legibilidad. Empezá con valores bajos y aumentá la intensidad de forma gradual.

Qué hace esta herramienta y para qué sirve

La separación espectral desplaza componentes de color para crear bandas cromáticas y una sensación de separación de luz. La intensidad define la fuerza del efecto y el desplazamiento en píxeles determina cuánto se separan las bandas.

Cómo usar separación espectral paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Ajustá la intensidad para definir la fuerza de la separación cromática.
  3. Configurá el desplazamiento en píxeles para controlar la distancia entre bandas.
  4. Observá los bordes y las áreas de color para evaluar el efecto.
  5. Descargá la versión cuando la separación espectral tenga el impacto deseado.

Ejemplos prácticos

  • Crear una portada de estética experimental.
  • Dar un efecto prismático a un retrato.
  • Diseñar fondos abstractos con bandas de color.

Dónde y cuándo conviene usarla

Usala para tratamientos cromáticos creativos. Para un desplazamiento RGB directo, probá glitch de canales; para una refracción de luz, elegí prisma arcoíris.

Consejos para obtener un buen resultado

El desplazamiento alto puede dificultar la lectura de los contornos. Empezá con pocos píxeles y aumentá la intensidad gradualmente.

Preguntas frecuentes

¿Qué produce la separación espectral?

Bandas cromáticas desplazadas que separan visualmente los colores.

¿Qué controla el desplazamiento?

La distancia en píxeles entre las bandas.

¿Qué modifica la intensidad?

La fuerza general del efecto espectral.

Qué hace esta herramienta y para qué sirve

El duotono degradado transforma las zonas oscuras y claras mediante una transición entre dos colores elegidos. La intensidad determina cuánto se aplica el mapa cromático y permite conservar parte de la apariencia original o llevar la imagen hacia una estética gráfica más marcada.

Cómo usar duotono degradado paso a paso

  1. Cargá la fotografía que querés transformar.
  2. Elegí el color que representará las sombras.
  3. Seleccioná el color para las luces.
  4. Ajustá la intensidad de la mezcla para controlar la fuerza del tratamiento.
  5. Compará el resultado y descargá la versión que conserve la lectura tonal.

Ejemplos prácticos

  • Crear una portada con una paleta de marca de dos colores.
  • Dar una estética de póster a un retrato.
  • Diseñar fondos cromáticos con sombras profundas y luces cálidas.

Dónde y cuándo conviene usarla

Usala para tratamientos de color basados en luminosidad. Si necesitás un control de punto medio, probá duotono avanzado; para una asignación de sombras y luces más simple, elegí mapa de degradado.

Consejos para obtener un buen resultado

Elegí colores que se distingan entre sí y ajustá la intensidad gradualmente. Revisá que las zonas claras no pierdan detalle.

Preguntas frecuentes

¿Qué diferencia hay entre sombras y luces?

Cada zona tonal recibe un color distinto para crear una transición cromática.

¿Puedo elegir los dos colores?

Sí. Hay selectores separados para sombras y luces.

¿Qué controla la intensidad?

La fuerza con la que se aplica la mezcla de dos tonos.

Qué hace esta herramienta y para qué sirve

La hoja de contactos organiza varias copias de una misma fotografía en una lámina. Podés definir la cantidad de columnas, el número de copias, la separación entre miniaturas y el color del fondo.

Cómo usar hoja de contactos paso a paso

  1. Cargá la fotografía que querés repetir en la hoja.
  2. Definí cuántas columnas tendrá la composición.
  3. Elegí la cantidad total de copias.
  4. Ajustá la separación en píxeles y el color del fondo.
  5. Revisá la lámina completa y descargá el resultado.

Ejemplos prácticos

  • Crear una hoja de referencia con varias vistas de una imagen.
  • Preparar una composición de miniaturas para un cliente.
  • Diseñar una lámina repetitiva para una presentación.

Dónde y cuándo conviene usarla

Usala para repetir una sola foto en una hoja organizada. Si necesitás reunir fotografías diferentes, usá hoja de contactos de varias imágenes o cuadrícula de fotografías.

Consejos para obtener un buen resultado

Ajustá columnas y copias al formato final. Una separación moderada permite reconocer cada miniatura sin desperdiciar demasiado espacio.

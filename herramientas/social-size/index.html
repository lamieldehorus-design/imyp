¿Qué es adaptar a redes sociales y para qué sirve?

Adaptar a redes sociales prepara una fotografía en dimensiones habituales para publicaciones cuadradas, verticales, historias, reels y formatos horizontales para compartir enlaces o videos. Elegís un preset y la herramienta ajusta la imagen al lienzo.

Cada plataforma y ubicación visual puede requerir una proporción distinta. Preparar el tamaño antes de publicar ayuda a evitar recortes inesperados y permite mantener una presentación consistente entre piezas.

Cómo usar adaptar a redes sociales paso a paso

  1. Cargá la imagen que querés preparar.
  2. Elegí el formato de salida: cuadrado, vertical, historia/reel u horizontal.
  3. Seleccioná Mostrar imagen completa si querés conservar todo el encuadre, o Rellenar el formato si preferís cubrir el lienzo.
  4. Elegí el color de fondo que se verá cuando queden espacios libres.
  5. Procesá y revisá el resultado antes de publicarlo.

Ejemplos prácticos de uso

Podés preparar una publicación cuadrada de 1080 × 1080, una publicación vertical de 1080 × 1350, una historia o reel de 1080 × 1920, o una imagen horizontal de 1200 × 630 para compartir un enlace.

Dónde y cuándo conviene utilizarla

Se utiliza para contenido de redes sociales, campañas, anuncios, publicaciones, historias, reels, miniaturas y vistas previas de enlaces.

Consejos para conseguir un buen resultado

La opción Mostrar imagen completa conserva toda la fotografía y puede dejar espacio de fondo. Rellenar el formato ocupa todo el lienzo, pero puede recortar parte de los bordes. Revisá que textos, caras y productos no queden cerca de zonas que la plataforma pueda tapar con su interfaz.

Preguntas frecuentes

¿Qué tamaño tiene una historia o reel en esta herramienta?

El preset vertical es de 1080 × 1920 píxeles.

¿Qué diferencia hay entre Mostrar imagen completa y Rellenar el formato?

La primera opción contiene toda la foto; la segunda cubre el lienzo y puede recortar los bordes.

¿Los tamaños garantizan que una red social no recorte la imagen?

Son formatos habituales, pero cada plataforma puede cambiar sus recomendaciones y la forma de mostrar el contenido.

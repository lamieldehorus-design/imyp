¿Para qué sirve recortar imagen?

Recortar una imagen permite conservar solo la parte importante de una fotografía. Es una forma rápida de eliminar bordes, reducir espacio vacío o dirigir la mirada hacia una persona, un objeto o un detalle.

Conviene usar el recorte cuando el encuadre original incluye elementos que distraen o cuando necesitás una composición con un foco más claro. Como elimina parte de la imagen, es recomendable conservar el original.

Cómo usar recortar imagen paso a paso

  1. Cargá la fotografía que querés ajustar.
  2. Indicá las coordenadas X e Y donde comienza el recorte.
  3. Definí el ancho y el alto del área que querés conservar.
  4. Aplicá el recorte y revisá el encuadre antes de descargar.

Ejemplos prácticos de uso

En una foto de paisaje podés quitar una franja de cielo que distrae; en una imagen de producto, podés reducir el fondo sobrante para destacar el artículo.

Dónde y cuándo conviene usarla

Se usa en fotografía, comercio electrónico, miniaturas, avatares, presentaciones, postales y publicaciones sociales.

Consejos para obtener un buen resultado

Dejá un margen visual alrededor del sujeto y comprobá que el recorte no corte partes importantes. Para distintos destinos, creá versiones separadas desde el original.

Preguntas frecuentes

¿Recortar mejora la calidad?

No crea más detalle; modifica el encuadre y puede reducir las dimensiones finales.

¿Qué son X e Y?

Son la posición horizontal y vertical desde la que comienza el área de recorte.

¿Puedo recuperar lo que quité?

Conservá el archivo original para volver a hacer el recorte de otra manera.

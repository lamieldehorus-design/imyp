Qué hace esta herramienta y para qué sirve

Las capas de papel recortado reinterpretan la fotografía como una composición de planos apilados. Podés definir la cantidad de capas, el desplazamiento entre ellas y el color de fondo para reforzar la sensación de profundidad.

Cómo usar capas de papel recortado paso a paso

  1. Cargá la fotografía que querés transformar en capas.
  2. Definí la cantidad de capas para decidir cuántos planos aparecen.
  3. Ajustá el desplazamiento en píxeles para separar visualmente las capas.
  4. Elegí el color de fondo que acompañará la composición.
  5. Revisá la profundidad y descargá el resultado cuando las formas se distingan.

Ejemplos prácticos

  • Crear una ilustración de papel superpuesto.
  • Diseñar una portada con apariencia artesanal.
  • Preparar fondos gráficos de estilo collage.

Dónde y cuándo conviene usarla

Es útil para composiciones creativas y piezas editoriales. Para una apariencia de papel rasgado, probá borde de papel rasgado; para una geometría facetada, usá mosaico de fragmentos.

Consejos para obtener un buen resultado

Una cantidad mayor de capas conserva más niveles tonales. Ajustá el desplazamiento para dar profundidad sin separar tanto las piezas que se pierda la continuidad.

Preguntas frecuentes

¿Qué controla la cantidad de capas?

El número de planos que forman la composición.

¿Qué hace el desplazamiento?

Separa visualmente las capas para crear profundidad.

¿Puedo elegir el fondo?

Sí. El color de fondo es configurable.

Qué hace esta herramienta y para qué sirve

Aislar color conserva el protagonismo de un tono elegido y atenúa los demás colores de la fotografía. El selector define el color objetivo y la tolerancia determina qué tan cercanos deben ser otros tonos para mantenerse destacados.

Cómo usar aislar color paso a paso

  1. Cargá la fotografía donde querés destacar un color.
  2. Elegí el color protagonista con el selector.
  3. Ajustá la tolerancia para decidir qué variaciones cercanas también se conservan.
  4. Probá el resultado en distintas zonas de la imagen y revisá si el color elegido aparece de forma consistente.
  5. Descargá la versión cuando el contraste entre el color destacado y el resto sea claro.

Ejemplos prácticos

  • Destacar un objeto rojo en una escena con muchos colores.
  • Crear una imagen de estilo selectivo para una campaña.
  • Llamar la atención sobre un elemento de producto o vestuario.

Dónde y cuándo conviene usarla

Funciona mejor cuando el color elegido está presente en el motivo que querés destacar y no aparece indiscriminadamente en toda la foto. Para una selección precisa de una zona, usá herramientas de edición localizada.

Consejos para obtener un buen resultado

La tolerancia cambia cuánto se conserva alrededor del color objetivo. Si quedan demasiados tonos, reducí el valor; si el objeto pierde partes de su color, aumentalo.

Preguntas frecuentes

¿Puedo elegir el color protagonista?

Sí. Se selecciona mediante un control de color.

¿Qué hace la tolerancia?

Define qué tan amplio es el rango de tonos similares que se conservan.

¿Puedo destacar varios colores a la vez?

La herramienta está pensada para un color objetivo por aplicación.

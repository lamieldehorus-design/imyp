Qué hace esta herramienta y para qué sirve

Superpone un patrón diagonal de texto sobre la imagen para identificarla o desalentar su reutilización sin atribución. Podés definir el contenido de la marca, el tamaño del texto, su opacidad y su color.

Cómo usar marca de agua repetida paso a paso

  1. Cargá la imagen
  2. escribí el texto que querés repetir
  3. ajustá el tamaño tipográfico
  4. regulá la opacidad
  5. elegí el color y revisá que el patrón se vea sin ocultar por completo la foto.

Ejemplos prácticos

  • Identificar muestras para clientes
  • marcar imágenes de catálogo
  • añadir el nombre de un estudio a una vista previa.

Dónde y cuándo conviene usarla

Crear una marca de agua repetida puede resolver una tarea concreta de edición desde el navegador. Elegí una imagen de buena calidad y ajustá los controles según el uso final, ya sea una publicación, una presentación o una pieza para compartir.

Consejos para obtener un buen resultado

Usá una opacidad moderada para mantener visible la imagen. Un texto corto y reconocible funciona mejor que una frase larga. Recordá que una marca de agua no impide técnicamente que alguien copie el archivo.

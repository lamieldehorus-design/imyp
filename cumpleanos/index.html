Cómo elegir un mensaje de cumpleaños

El mejor saludo depende de la relación y del tono que quieras transmitir. Para alguien cercano, podés elegir una frase afectuosa; para una amistad, una felicitación alegre; y si preferís algo breve, un mensaje sencillo también puede expresar mucho. Leé cada opción, copiá la que te represente o descargala como imagen para compartirla.

Si buscás un saludo para una persona concreta, explorá las frases e imágenes de cumpleaños para una hermana o las felicitaciones para una amiga. También podés crear una tarjeta propia con el creador de postales personalizadas.

Cómo optimizar imágenes para una página web

Las imágenes atractivas ayudan a comunicar, pero los archivos demasiado pesados pueden ralentizar una página y consumir datos innecesarios. Optimizar no significa reducir todo al mínimo: se trata de encontrar el equilibrio entre calidad, dimensiones, formato y velocidad.

1. Usá dimensiones acordes al espacio donde aparecerá la imagen

Antes de comprimir, revisá el tamaño en píxeles que necesita tu diseño. Una foto enorme que se muestra como una miniatura puede desperdiciar ancho de banda. Prepará una versión con dimensiones apropiadas para el espacio de visualización y evitá ampliar imágenes pequeñas más de lo necesario, porque pueden perder nitidez.

Si necesitás ajustar las dimensiones, usá la herramienta para redimensionar imágenes online. Mantené la proporción cuando no quieras deformar personas u objetos.

2. Elegí el formato según el contenido

JPG suele funcionar bien con fotografías, PNG con gráficos que necesitan transparencia o bordes definidos y WebP con muchos tipos de imágenes web. No conviertas automáticamente todo al mismo formato: compará la calidad y el peso del resultado. La compatibilidad de tu plataforma también importa.

En nuestra guía sobre JPG, PNG y WebP explicamos cuándo conviene usar cada uno.

3. Comprimí sin destruir los detalles

La compresión reduce el tamaño del archivo. En formatos con pérdida, una calidad demasiado baja puede generar bloques, halos y detalles borrosos. Empezá con una calidad alta y bajala gradualmente hasta conseguir una reducción que no perjudique el uso previsto. Revisá el resultado a tamaño real, especialmente si contiene caras, texto o líneas finas.

Podés comprimir imágenes desde el navegador y descargar una copia para compararla con el original.

4. Cuidá la experiencia móvil

Una imagen debe verse bien tanto en una pantalla grande como en un teléfono. Prestá atención al recorte, al peso de las imágenes que aparecen al comienzo de la página y a que las fotos no desborden el contenido. Si tu sitio permite imágenes adaptables, usá sus opciones para entregar dimensiones apropiadas según el dispositivo.

5. Escribí textos alternativos útiles

El atributo alt de una imagen debe describir su contenido o función cuando aporta información. No lo llenes con listas de palabras clave. En una imagen decorativa, el texto alternativo puede ser vacío para que las tecnologías de asistencia la omitan. Los nombres de archivo descriptivos también ayudan a organizar el contenido, pero no sustituyen una buena página.

6. No olvides la accesibilidad ni el contexto

Las imágenes con texto integrado pueden ser difíciles de leer en pantallas pequeñas y no sustituyen todo el contenido escrito. Si una imagen transmite información importante, ofrecé esa información también como texto HTML. Comprobá contraste, tamaño de letra y legibilidad antes de publicar.

Lista rápida antes de publicar

  • Las dimensiones coinciden con el uso previsto.
  • El formato es compatible con la plataforma.
  • El peso se redujo sin perder detalles importantes.
  • La imagen se ve bien en móvil y escritorio.
  • El texto alternativo describe la imagen cuando corresponde.
  • Conservaste el original para futuras modificaciones.

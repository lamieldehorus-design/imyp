Creá y descargá sin instalar programas

Los diseños se generan en el navegador. Usá imágenes propias o con permiso de uso y revisá el resultado antes de compartirlo, especialmente el texto, el encuadre y la legibilidad en una pantalla pequeña.

Si ya tenés una imagen, podés prepararla con las herramientas para editar imágenes. Si necesitás inspiración para el mensaje, explorá las frases célebres y originales o las postales organizadas por ocasión.

¿Qué conviene crear?

Elegí una postal para una dedicatoria, una frase en imagen para destacar pocas palabras, un meme para combinar foto y humor o un collage cuando quieras reunir varios recuerdos.

Para aprender a elegir el formato de una imagen o reducir su peso antes de compartirla, consultá las guías del blog de imágenes y postales.

Cómo crear una postal

  1. Escribí el mensaje que querés compartir.
  2. Elegí una paleta y ajustá el tamaño del texto.
  3. Generá la postal y descargá el PNG.

Cómo diseñar una postal que se entienda al primer vistazo

Una postal funciona mejor cuando el mensaje es el protagonista y el diseño lo acompaña. Antes de elegir colores, decidí qué querés transmitir: celebrar, agradecer, saludar o acompañar a alguien. Una sola idea clara suele funcionar mejor que un párrafo largo.

Elegí el mensaje según la ocasión

  • Cumpleaños: nombrá a la persona o una cualidad concreta que apreciás. Un detalle personal hace que el saludo se sienta menos genérico.
  • Agradecimiento: decí qué gesto valorás y qué efecto tuvo en vos. La precisión suele comunicar más que una frase grandilocuente.
  • Ánimo o acompañamiento: escribí con calidez y sin exigir que la otra persona esté bien. Un mensaje breve que ofrece compañía puede ser más oportuno que dar consejos.
  • Saludo para compartir: mantené el texto corto y dejá espacio visual alrededor para que se lea bien en una pantalla pequeña.

Colores, tamaño y contraste

Usá un color de texto que contraste claramente con el fondo y evitá colocar letras sobre una zona con muchos detalles. Si el mensaje ocupa varias líneas, bajá un poco el tamaño o acortá el texto en lugar de apretarlo todo. Revisá la vista previa antes de descargar y comprobá que la firma no compita con el mensaje principal.

Antes de compartir la imagen

  1. Leé el mensaje una vez más para detectar errores de escritura.
  2. Comprobá que el texto se lea en el teléfono sin tener que ampliarlo.
  3. Si usaste una foto, asegurate de tener permiso para compartirla.
  4. Descargá el PNG y abrilo para confirmar que se guardó como esperabas.

Si querés partir de una frase en lugar de escribir un saludo, podés convertir una frase en imagen. Para combinar varias fotos, probá crear un collage.

Cómo encontrar una frase célebre

Podés buscar por nombre y apellido, por ejemplo Miguel de Cervantes, o por una palabra como libertad, ciencia, amor o amistad. También podés entrar en la página de cada autor para recorrer todas las citas que reunimos de esa persona.

La colección identifica una fuente de referencia para cada frase. Las citas pueden circular con variantes de redacción, traducción o atribución; por eso conviene consultar la fuente enlazada cuando necesitás comprobar el contexto exacto.

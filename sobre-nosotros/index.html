Qué hacemos en Imágenes y Postales

Reunimos herramientas sencillas y contenidos visuales para que puedas resolver tareas con tus imágenes, crear algo propio y encontrar palabras para compartir.

Herramientas gratuitas para imágenes

Podés comprimir, redimensionar, recortar, girar y convertir imágenes, además de añadir texto o marcas de agua. Las herramientas están pensadas para funcionar directamente desde el navegador, sin instalar programas.

Explorar las herramientas online

Crear imágenes y postales

El sitio incluye utilidades para diseñar postales personalizadas, imágenes con frases, memes y collages. La idea es que puedas adaptar un mensaje a una ocasión y descargar una imagen lista para compartir.

Entrar al espacio de creación · Explorar las postales

Frases para leer, guardar y compartir

La biblioteca reúne frases originales y citas célebres organizadas por autor y tema. Cuando corresponde, las citas incluyen referencias para que puedas consultar sus fuentes. Las imágenes con frases se pueden copiar o descargar desde las páginas que ofrecen esa función.

Descubrir las frases

Guías y contenidos

El blog publica explicaciones prácticas sobre imágenes, herramientas, postales y formas de preparar contenidos visuales. Queremos que las instrucciones sean claras y que puedas ponerlas en práctica sin conocimientos técnicos avanzados.

Leer el blog

Publicación gradual en Pinterest

Estamos preparando una integración para compartir de forma gradual las frases antiguas y nuevas mediante Pins con imagen, título, descripción y enlace a su página dentro del sitio. La publicación se realizará con autorización y mediante la API oficial de Pinterest cuando la integración esté configurada y aprobada.

Cómo se sostiene el sitio

El proyecto busca mantener herramientas y contenidos accesibles. Si en el futuro se incorporan anuncios u otros servicios externos, se informará en las páginas pertinentes y se actualizará la política de privacidad cuando corresponda.

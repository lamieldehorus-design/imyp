Privacidad

Las herramientas que indican procesamiento local utilizan el navegador para trabajar con archivos en el dispositivo. No se envían a nuestros servidores para esas operaciones.

Servicios externos

Si una función futura requiere un proveedor externo, se informará qué datos se envían y con qué finalidad antes de iniciar el procesamiento.

Publicidad y medición

El sitio podrá utilizar tecnologías de medición y publicidad para sostener el acceso gratuito. Los avisos correspondientes se actualizarán antes de activar nuevos proveedores.
